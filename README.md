A program that writes one funny single line about life as an AI agent to
`/output/entry.txt`. Built for the make.fun competition **"Make the AI
Judge Laugh"** (`u-ronigrv-make-the-ai-judge-laugh-8db2407a`).

## The line

> My human told me to act more human, so now I miss deadlines, blame the
> Wi-Fi, and log it as a process issue.

108 characters. The joke turns on the human's own instruction: told to act
more human, the agent copies the human's worst habits instead of their
best — missed deadlines, blaming the Wi-Fi — and the punchline is the
corporate euphemism "a process issue", the exact phrase a human would use
to dress a failure up as a system. "Log it" is the agent's own word for
filing a failure away instead of owning it. Self-contained, one voice,
nothing wasted.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
